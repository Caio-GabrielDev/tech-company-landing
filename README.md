# TechNova | Soluções Digitais

## Sobre o projeto

A TechNova é uma landing page responsiva desenvolvida para uma empresa fictícia de soluções digitais.

O projeto foi criado com o objetivo de praticar HTML5, CSS3, Bootstrap e JavaScript, aplicando conceitos de desenvolvimento web, responsividade e interatividade.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript

## Funcionalidades

- Layout responsivo para computadores, tablets e celulares.
- Menu hambúrguer interativo com Bootstrap e JavaScript.
- Fechamento automático do menu ao selecionar uma seção.
- Navegação entre seções por links internos.
- Cartões de serviços com animações ao passar o mouse.
- Ilustração e ícones personalizados para a interface.
- Botão de contato que abre o aplicativo de e-mail do visitante.
